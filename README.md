# ولّعها — نسخة ويب تجريبية

ثلاث واجهات متصلة بقاعدة SQLite واحدة: تطبيق ويب للعميل، تطبيق ويب للمندوب، ولوحة تحكم المسؤول. تشمل أقسام المنتجات وصورها وكمياتها، طلب توصيل أوردر، طلب مشوار بتوك توك أو موتوسيكل أو سيارة، تسعير الخدمات يدويًا، الدفع النقدي أو إثبات تحويل المحفظة، رسوم توصيل مختلفة لكل منطقة، موافقة العميل على السعر، مراجعة المسؤول قبل إسناد أي طلب، وتحديث مراحل التسليم. يحدد العميل موقع العنوان بالنقر على الخريطة أو باستخدام موقعه الحالي، مع كتابة وصف العنوان. تعرض لوحة الإدارة علامات الطلبات الجارية وآخر مواقع المندوبين، ويرى العميل موقع مندوبه أثناء الطلب فقط. مشاركة الموقع من متصفح المندوب اختيارية وأثناء وجود طلب جارٍ فقط.

الخرائط تستخدم Leaflet وخرائط OpenStreetMap مع إظهار نسب المصدر. تحتاج اتصالًا بالإنترنت؛ لا يوجد تقدير وقت وصول أو تتبع في الخلفية عند إغلاق واجهة المندوب. الموقع المعروض آخر نقطة مرسلة، وقد يتأخر حسب إذن الموقع واتصال المندوب.

يمكن لكل حساب تغيير كلمة المرور من «إعدادات حسابي»، مع إغلاق جلساته الأخرى. تُقيّد محاولات الدخول الفاشلة المتكررة على نفس الهاتف وعنوان الاتصال مؤقتًا؛ هذه حماية أولية لا تغني عن تدقيق أمني قبل النشر.

## التشغيل

### فتح الداشبورد على Windows من غير استضافة

فك ضغط الملف، وثبّت Python 3.10 أو أحدث إن لم يكن موجودًا. افتح `start_windows.bat` من داخل مجلد `wallaha_demo`، واختر كلمة مرور المسؤول أول مرة (10 أحرف على الأقل)، وأبقِ نافذة التشغيل مفتوحة. إذا فتح المتصفح قبل اكتمال تشغيل الخادم، حدّث الصفحة بعد لحظة. الروابط على **نفس الكمبيوتر فقط**:

| الواجهة | الرابط |
| --- | --- |
| لوحة تحكم المسؤول | http://127.0.0.1:8080/admin |
| تطبيق العميل | http://127.0.0.1:8080/customer |
| تطبيق المندوب | http://127.0.0.1:8080/driver |

يدخل المسؤول باسم المستخدم `owner` أو الهاتف `01113887292` وكلمة المرور التي اختارها أول مرة. يمكن تعيين اسم مختلف قبل أول تشغيل بمتغير `WALLAHA_ADMIN_USERNAME` (حروف إنجليزية، يبدأ بحرف، 3–30 رمزًا). لا تُشارك كلمة المرور. بعد تشغيل أول مرة، تظل محفوظة مشفّرة في قاعدة البيانات المحلية؛ كتابة كلمة مختلفة في نافذة التشغيل اللاحقة **لا تغيّرها**، بل استخدم «إعدادات حسابي» داخل التطبيق. لإنشاء مندوب، ادخل لوحة التحكم أولًا وأضفه باسمه ورقم هاتفه واسم مستخدم وكلمة مرور؛ ويمكن للعميل إنشاء حساب من واجهته. نافذة التشغيل يجب أن تظل مفتوحة أثناء التجربة. هذه الروابط المحلية لا تفتح من أجهزة أخرى ولا من `walla3ha.com`.

المسؤول يرى كل الطلبات ويستطيع إضافة المنتجات وتعديل سعرها ومخزونها وإخفاءها من واجهة العميل من دون حذف سجل الطلبات السابقة. يمكنه تشغيل أو إيقاف الخدمات الأساسية (منتجات، توصيل أوردر، مشوار توك توك، مشوار سيارة)، وإضافة خدمة جديدة بسعر يحدده بعد استلام الطلب ويوافق عليه العميل. تظهر آخر إحداثيات الطيار ووقت إرسالها في الداشبورد أثناء طلب جارٍ إذا اختار مشاركة موقعه وترك شاشة الطيار مفتوحة؛ تُحدَّث واجهة المسؤول دوريًا كل 15 ثانية عندما لا يحرر حقولًا.

تملك واجهة العميل والمندوب والإدارة ملفات تثبيت PWA منفصلة. بعد النشر على HTTPS، يعرض المتصفح الذي يدعم التثبيت زر «تثبيت الواجهة» عند تحقق شروطه؛ في غياب الزر يمكن تجربة «إضافة إلى الشاشة الرئيسية» من المتصفح. هذه ليست ملفات APK مستقلة ولا تغني عن استضافة الخادم. يوجد زر اختياري لتنبيهات الطلبات في لوحة المسؤول والمندوب؛ يعمل بإذن المتصفح وأثناء فتح الواجهة فقط، ولا يرسل إشعارات عند إغلاق التطبيق أو الهاتف.

### تشغيل يدوي على أي نظام

ثبت Python 3.10 أو أحدث، ثم شغّل من هذا المجلد:

```bash
export WALLAHA_ADMIN_PASSWORD='choose-a-long-private-password'
python3 server.py
```

رقم دخول المسؤول مبدئيًا `01113887292`، واسم المستخدم `owner`، ويمكن تغييرهما **قبل أول تشغيل** بمتغيري `WALLAHA_ADMIN_PHONE` و`WALLAHA_ADMIN_USERNAME`. افتح `http://127.0.0.1:8080/admin` للمسؤول، `/customer` للعميل، و`/driver` للمندوب على الجهاز نفسه. يضاف حساب المندوب من لوحة التحكم باسم مستخدم ورقم هاتف وكلمة مرور. يسجل العميل حسابًا جديدًا من واجهته. يؤخذ الاسم والهاتف المسجلان في الحساب تلقائيًا عند إرسال الطلب. تفتح الواجهات الثلاث من روابط منفصلة، ويمكن تثبيت واجهات الويب من متصفح يدعم تطبيقات الويب عند توفير HTTPS. ملفات ZIP لا تحتوي قاعدة بيانات المستخدمين.

## خطوات التجربة

1. ادخل كمسؤول، أضف منتجًا بصورته، ثم أضف مندوبًا لمنطقة أبو صير.
2. سجل عميلًا، وأرسل طلب منتجات في أبو صير. إذا اختار المحفظة، يلزمه إثبات تحويل وتأكيد المسؤول لوصول المال.
3. اجعل الأوردر جاهزًا للاستلام من لوحة التحكم. ادخل كمندوب، ثم أكد الاستلام والطريق والتسليم. في الدفع النقدي يؤكد المندوب تحصيل المبلغ؛ تظهر العهدة غير المسوّاة للمسؤول حتى يؤكد استلامها.
4. لخدمة توصيل أوردر أو مشوار، يسجل العميل المسار أولًا، ثم يحدد المسؤول السعر ويوافق عليه العميل صراحةً أو يرفضه. إن اختيرت المحفظة يرفع العميل الإثبات بعد الموافقة، ويؤكد المسؤول وصول المال قبل الإسناد.
5. يستطيع المندوب السماح بمشاركة موقعه أثناء الطلب الجاري فقط؛ ترى آخر موقع ووقت تحديثه من لوحة التحكم.

## حدود النسخة قبل الإطلاق

هذه نسخة تطوير محلية، وليست APK منشورًا. لا تستخدمها مع بيانات عملاء أو مدفوعات حقيقية. تسجيل الهاتف غير موثق برمز SMS، ولا يوجد استرداد كلمة مرور أو إشعارات أو تخزين صور خارجي أو نسخ احتياطي أو بوابة دفع أو إرسال واتساب تلقائي. التسعير للمشاوير والتوصيل يدوي ويعرض على العميل للموافقة داخل التطبيق. مشاركة الموقع تتطلب HTTPS أو localhost وتعمل أثناء فتح شاشة المندوب فقط. يلزم استضافة آمنة، حماية واجهات API، قيود لمحاولات الدخول، مراقبة ونسخ احتياطي، واختبار حمل وأمان، وتجهيز تطبيقات Android وتسجيل Google Play قبل النشر. عرض/بيع الأدوية يحتاج شريك صيدليًا أو جهة مخولة ومسارًا متوافقًا مع شروط النشاط المحلية؛ وضع مراجعة إدارية وصورة وصفة في البرنامج لا يكفي وحده لذلك. لا تنشر قسم الأدوية قبل إتمام هذا الترتيب.

## تشغيل اختياري داخل Docker

بعد ضبط كلمة مرور خاصة بك، يمكن تشغيله محليًا مع حفظ البيانات في مساحة Docker دائمة باسم `wallaha_data`:

```bash
docker build -t wallaha-dev .
docker run --rm -p 127.0.0.1:8080:8080 -v wallaha_data:/data \
  -e WALLAHA_ADMIN_PASSWORD='choose-a-long-private-password' \
  -e WALLAHA_ADMIN_PHONE='01113887292' wallaha-dev
```

في Docker يعمل الخادم على جميع واجهات **الحاوية** فقط، ومنفذ المضيف مقيد على `127.0.0.1`. هذه الإعدادات لا تنشره على الإنترنت. لفتحه للناس يلزم إعداد HTTPS واستضافة آمنة وتوثيق هواتف ومراجعة أمنية قبل ذلك.

## الدومين المسجل

أفاد صاحب المشروع بشراء `walla3ha.com`. اقرأ `DOMAIN_SETUP.md` لخطوات ربطه بعد اختيار استضافة مناسبة. تسجيل الاسم لا يعني أن الموقع منشور حاليًا.
